# memos for iPhone

Native capture app: record a clip from Ray-Ban Meta glasses (or a simulated camera), keep it on the phone, and upload
it to the memos upload API with a durable, resumable queue. Setup, testing and the hosted-server flow are in
[docs/PHONE_APP.md](../../docs/PHONE_APP.md).

| Project | Target | Camera feed | Requirements |
| --- | --- | --- | --- |
| `SceneCapture.xcodeproj` | SceneCapture | Live glasses stream via the Meta Wearables Device Access Toolkit 1.0.1 (Swift Package Manager) | Paired glasses, iPhone, Meta AI app, the DAT SDK's supported Xcode |
| `SceneCaptureDemo.xcodeproj` | SceneCaptureDemo | Animated, clearly labelled demo scene (no SDK, no camera permission) | Xcode 15.4+, iOS 17.2+, iPhone or Simulator |

```
apps/ios/
├── SceneCapture/            shared sources for both apps (flat: the project generator only picks up *.swift here)
│   ├── SceneCaptureApp.swift   app entry and tabs (Capture, Memories, Party, Settings)
│   ├── SceneLibrary.swift      local library and durable upload queue
│   ├── Recorder.swift          H.264 MP4 writer
│   ├── AccountKey.swift        portable account credentials
│   ├── CaptureRequirements.swift
│   ├── GlassesCapture.swift    live feed (SceneCapture only)
│   └── DemoCapture.swift       simulated feed (SceneCaptureDemo only)
├── SceneCapture.xcodeproj/      generated
├── SceneCaptureDemo.xcodeproj/  generated
└── Tests/                   command-line check programs compiled with `xcrun swiftc` (not part of either project)
```

Both Xcode projects are generated by `npm run ios:generate` (`scripts/generate_xcode_project.py`). Rerun it after
adding or removing a Swift file in `SceneCapture/`; it keeps each project's team, bundle ID and Meta app settings.

[Acceptable Use Policy](https://wearables.developer.meta.com/acceptable-use-policy).
