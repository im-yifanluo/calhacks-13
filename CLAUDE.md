# memos: notes for agents

Ray-Ban Meta glasses video → a 3D memory that people relive together in VR (Quest 3S), on a phone or a desktop:
things move as in the video; pause time to grab and throw objects and branch alternate takes. A finished CalHacks 13
project (October 2026).

## Checks

`npm run format:check`, `npm run lint`, `npm run typecheck`, `npm test` (every package), `npm run build`; for the
pipeline `pip install -e "pipeline[dev]"`, `ruff check .`, `ruff format --check .`, `pytest pipeline`. CI runs all of
them. Live suites (`npm run test:integration`, `test:party`, `test:adapter`, `test:connections`, `test:upload-api`)
need a local SpacetimeDB 2.13 (`npm run stdb:start`, `npm run stdb:publish:local`).

## Rules that bite

- **The scene format exists twice:** `packages/shared/src/manifest.ts` (+ `validate.ts`) and
  `pipeline/memreplay/manifest.py`. Change them together.
- **Never hand-edit generated files or lockfiles.** Regenerate `apps/web/src/module_bindings/` with
  `npm run stdb:generate` (SpacetimeDB CLI 2.13.0), the Xcode projects with `npm run ios:generate`, and
  `package-lock.json` with `npm install`.
- **SpacetimeDB module code must be deterministic:** no `Math.random()` or `Date.now()`; use `ctx.random` and
  `ctx.timestamp`. `server/spacetime/src/index.ts` may export only the schema (default) and reducers; helpers stay
  in `helpers.ts`. Wire and SQL names are snake_case; TypeScript names are camelCase.
- **The `spacetime` CLI defaults to Maincloud.** Pass `-s http://127.0.0.1:<port>` for local work; local SpacetimeDB
  runs on 3055 (`STDB_PORT`).
- **`pipeline/memreplay/worker.py` keeps stdlib-only imports at module level:** an integration suite loads it as a
  bare file, and it loads `source_check.py` by path.
- **Spark needs a `SparkRenderer`** in the scene, or splats never draw.
- **The dev server answers unknown paths with the viewer** (party codes live at `/CODE`), so static pages need their
  full path, e.g. `/scenes/index.html`.
- **Big assets** (`.ply`, `.spz`, `.glb`, `.mp4`, `.mov`) never go in git; local scenes live in
  `apps/web/public/memories/` (ignored).
- **Hosted settings** (database, upload API, former origin) live in `apps/web/.env.hosted`.
- **Commit or push only when asked.**
